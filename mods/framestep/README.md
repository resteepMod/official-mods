# Frame step

F10 freezes the whole world (the engine's stop mode), "." runs one simulation step, "," ten.
F10 again lets it run. The game cuts to its pause camera while frozen.

A script mod (`main.lua`, ReSteep's Lua API: MODDING.md).

**Multiplayer:** single player only: freezing the simulation with others around is not tried (your rider may stop
for them, or the session may drop). Switch it off before you join a server.
