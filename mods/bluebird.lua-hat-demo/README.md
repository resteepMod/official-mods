# Lua Hat Demo

A striped beanie with a pompom, made by a build script (build.lua) from the colours you pick. Shows own models and own textures without a 3D program.

Install: drop the .resteep file into ReSteep's mods folder (or add it in the launcher's Mods page).

**Multiplayer:** must match: the hat is an item, so every player on the server needs the same mod, and the server
runs it too (the server lists it; when you join, ReSteep shows it as missing or different if yours is not the same).
Its colours are built on each PC from that player's settings: others see your hat in the colours they picked.
