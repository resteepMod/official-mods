# ReSteep Boxes

A wireframe of the space every slot may use: start here before you model your own gear.

Install: drop the .resteep file into ReSteep's mods folder (or add it in the launcher's Mods page).

**Multiplayer:** must match: the boxes are items, so every player on the server needs the same mod, and the server
runs it too (the server lists it; when you join, ReSteep shows it as missing or different if yours is not the same).
