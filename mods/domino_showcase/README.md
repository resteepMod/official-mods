# Domino Showcase

Everything a mod's Domino script can do today, one key each, in the Alps and Japan (`content.scripts`, idle until started): J picks the next effect, K runs it, L stops them all; 1-8 run one directly (a tooltip, the game's progression sounds, a light change, a kicker 15 m ahead of you (Alps), a skydrop 400 m above you, a respawn, ForceStopPlayer, the whole show).

**Multiplayer:** must match: its scripts and the kicker's template are placed in the maps (content.scripts,
content.worlds), so every player on the server needs the same mod, and the server runs it too (the server lists it;
when you join, ReSteep shows it as missing or different if yours is not the same). The effects are yours: the
kicker, the tooltip and the light show on your PC only; others see you ride off a kicker they do not have, or drop
from the sky.
