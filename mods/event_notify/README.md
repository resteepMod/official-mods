# Event notifications

Every event ReSteep raises shows a notification (and a line in the MODS console) when it
fires. For checking that the events work. "frame" is left out (it fires every frame); "key" shows the key name.
A zone (10 m around where the rider first appears) makes zone_enter / zone_exit fire; press F4 to send a custom event.

A script mod (`main.lua`, ReSteep's Lua API: MODDING.md).

**Multiplayer:** yes, only you need it; the notes are on your screen only.
