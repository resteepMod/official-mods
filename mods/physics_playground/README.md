# Physics Playground

Changes the ski and snowboard physics while you ride (`resteep.handling`): F5 jump strength (x1, x2, x4, x8), F6 air (normal, floaty, heavy), F9 ground (normal, fast, slow), F11 everything as shipped. Switching the mod off puts the shipped physics back.

**Multiplayer:** works, but others see the result: your rider jumps, floats or drops as you set it. Your challenge
times and mod-board values use the changed physics: switch it off (F11) before a race.
